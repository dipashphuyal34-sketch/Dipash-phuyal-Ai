# Dipash Phuyal Intelligence

A refined personal AI assistant designed for productivity, creative writing, and knowledge retrieval. Custom built for **Dipash Phuyal**.

## Features

- **Swiss Modern UI**: Clean, minimalist, and functional design.
- **Gemini AI Integration**: Advanced reasoning and creative drafting powered by Google Gemini.
- **Secure Gateway**: OpenAI-inspired login screen.
- **Persistent Chat**: Conversations are saved to your local storage.
- **Professional Showcase**: Includes a high-end landing page for demonstrations.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **AI**: Google Generative AI (@google/genai)

## Setup

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file and add your Gemini API key:
   ```env
   VITE_GEMINI_API_KEY="your_api_key_here"
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```

## Deployment

To deploy this site to GitHub Pages or any static hosting:
1. Run `npm run build`.
2. Upload the contents of the `dist` folder to your hosting provider.
